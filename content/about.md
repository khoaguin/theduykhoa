# About Me
Hi! I'm Khoa Nguyen, a senior researcher and engineer specializing in AI and Privacy-Preserving Technologies.

## Background

I finished my Master Degree at Tampere University in Finland in 2021 with a focus on AI and Cybersecurity where I developed a deep interest in building systems that enable machine learning while protecting user security and privacy.

## Current & Past Work

I am a senior software engineer at <a href="https://openmined.org" target="_blank" rel="noopener noreferrer">OpenMined</a>, where I build AI evaluation and privacy-preserving machine learning technologies. Currently I'm focused on:
- <a href="https://github.com/ScreamingFace/screamingface" target="_blank" rel="noopener noreferrer">ScreamingFace</a>: An open toolkit for composing model fusions — several models answering the same question, reduced to one answer — and scoring them honestly against real benchmarks. Every run compiles to a single short line of text that anyone can replay, and model calls are cached and shared, so verifying someone else's result costs minutes instead of a budget. A result is only worth as much as your ability to rerun it.

Previously I worked on:
- <a href="https://www.syftbox.net/" target="_blank" rel="noopener noreferrer">SyftBox</a>: An open-source privacy-first, offline-capable AI infrastructure that enables developers to build applications, run federated learning, and advance Privacy-Enhancing Technologies (PETs) research.
- <a href="https://github.com/OpenMined/syft-flwr" target="_blank" rel="noopener noreferrer">syft-flwr</a>: A privacy-preserving distributed computing framework that combines Syftbox and <a href="https://github.com/adap/flower" target="_blank" rel="noopener noreferrer">Flower</a>. Enable federated learning, analytics, and federated RAG with secure job submission, approval workflows, and offline capability.
- <a href="https://github.com/OpenMined/syft-crypto-core" target="_blank" rel="noopener noreferrer">syft-crypto-core</a>: End-to-end encrypted communication and file synchronization for SyftBox using the Signal protocol.
- <a href="https://github.com/OpenMined/PySyft" target="_blank" rel="noopener noreferrer">PySyft</a>: OpenMined's flagship library for remote data science. It lets a researcher get answers from data they never see or copy, combining differential privacy, federated learning, and secure enclaves.

I have also been researching on privacy-preserving machine learning and AI Safety. You can find my humble scientific contributions on <a href="https://scholar.google.com/citations?user=9Cx8YUIAAAAJ&hl=en" target="_blank" rel="noopener noreferrer">Google Scholar</a>.

## AI Safety

I'm interested in AI Safety, especially evaluations, zero-trust system deployments, and AI security. One example is <a href="https://github.com/khoaguin/blindfold" target="_blank" rel="noopener noreferrer">Blindfold</a>, where a model owner, a benchmark owner, and an auditor run one evaluation together inside a secure enclave: nobody has to trust anybody, no secret leaves its owner, and only the score comes out.
